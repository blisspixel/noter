# Bundled font

`InterVariable.ttf` is the variable Inter typeface used for proportional
document text. Its weight axis gives Markdown headings and strong emphasis real
font weights instead of synthetic bolding.

The bundled file is the Inter variable font distributed in the locally verified
`cosmic-text` 0.16.0 crate. Its SHA-256 is
`4989b125924991b90d05b2d16e0e388c48f7d5bb8b30539bbf9c755278d0ccaf`.

Inter is distributed under the SIL Open Font License, Version 1.1. The complete
license accompanies the font in [Inter-OFL.txt](Inter-OFL.txt). The upstream
project is <https://github.com/rsms/inter>.
