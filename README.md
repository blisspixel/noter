# Noter

Noter is a focused, cross-platform editor for `.txt` and `.md` files, written in
Rust. It keeps the directness of a classic system notepad while treating
Markdown as a native document format.

Text Mode exposes the exact file source. Markdown Mode presents that same source
as formatted, directly editable content. Files remain ordinary UTF-8 text or
Markdown on disk, with no proprietary document format.

Noter does not require an account, collect telemetry, or fetch remote content
while editing.

## Status

Noter is pre-alpha and should not yet be the only editor used for important
data. The current build includes a basic editor shell, System, Light, and Dark
themes, an early source-backed Markdown Mode, conservative Markdown checks, and
an extensively tested durable-save foundation. The complete editing, recovery,
accessibility, Markdown, packaging, and release contracts are still in progress.

Verified work, remaining scope, and milestone exit criteria are maintained in
the [roadmap](docs/ROADMAP.md). Detailed engineering evidence stays under
[docs/](docs/README.md) rather than being repeated here.

## Install from source

There is no published binary release yet. Source installation requires the Rust
toolchain pinned by [rust-toolchain.toml](rust-toolchain.toml).

```powershell
git clone https://github.com/blisspixel/noter
cd noter
./scripts/install.ps1
```

```bash
git clone https://github.com/blisspixel/noter
cd noter
sh scripts/install.sh
```

Rerunning the installer replaces the existing Cargo-installed source build. The
supported release installer and updater contract is documented in
[docs/INSTALLATION.md](docs/INSTALLATION.md).

## Privacy

Editing performs no background network activity. A user-initiated update action
may open or contact the documented release channel, without document data or a
persistent installation identifier. See the [privacy contract](docs/PRIVACY.md)
for the complete and testable policy.
