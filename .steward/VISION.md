# VISION

Noter is a pure, reliable plain-text editor for 2026 that aims to be fast, trustworthy, and 'boring in the best way' with zero telemetry or bloat. It respects classic Notepad muscle memory while adding minimal modern quality-of-life improvements like system-matched themes and light in-editor Markdown syntax without a separate preview pane.
