# CONVENTIONS

The 'gate triple' (clean cargo fmt, cargo clippy -D warnings, and passing tests) is mandatory for all changes. Data-integrity paths require automated evidence before human verification, and bug fixes must include a failing reproduction test. The project strictly forbids unsafe code and uses panic=abort in release.
