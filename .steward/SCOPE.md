# SCOPE

In-scope features include atomic saves, line-ending and BOM fidelity, undo/redo, crash recovery, and light in-editor Markdown syntax. Explicitly out-of-scope for v0.1 are tabs, a separate Markdown preview pane, general syntax highlighting, LSP/git integration, plugins, and any network-dependent features like cloud sync or accounts.
